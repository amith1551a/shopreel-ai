## Database Initialization Flow

### On First App Startup:

```
1. Flask app creates Studio instance
   → Studio.__init__() runs
   → Creates schema for: videos, projects, generation_jobs, job_commands, higgsfield_jobs

   → BudgetGuard._init_schema() runs
   → Creates schema for: budget_ledger, budget_daily_summary, budget_monthly_summary
```

## Budget Data Survives Restarts

### Atomic Transaction Mechanism:

```python
# When user submits job:
with closing(self._get_conn()) as conn:    # Begin transaction
    # Check limits
    # Insert into budget_ledger (RESERVED)
    # Update budget_daily_summary
    # If all OK: COMMIT (auto on context exit)
    # If any error: ROLLBACK (auto on exception)

# If app crashes before COMMIT:
#   → Transaction automatically rolls back
#   → No budget reserved (safe for retry)

# If app crashes after COMMIT:
#   → Data safely persisted to disk
#   → Survives restart
#   → Budget respected on next run
```
