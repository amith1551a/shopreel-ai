🔗 API ENDPOINTS (5 TOTAL)
================================================================================

FREE ENDPOINTS (No Cost, No Side Effects):

  POST /api/higgsfield/parse-script
  └─ Input: {script}
  └─ Output: {storyboard, compressed, original_script}

  POST /api/higgsfield/preview-cost
  └─ Input: {model, duration_seconds, user_id}
  └─ Output: {estimated_cost_usd, budget_status, can_proceed}

  GET /api/higgsfield/budget?user_id=...
  └─ Output: {today{}, month{}, next_daily_reset_at, warn}

  GET /api/higgsfield/job/{job_id}/status?user_id=...
  └─ Output: {status, progress, video_url, error, costs}

PAID ENDPOINT (Atomically Reserves Budget):

  POST /api/higgsfield/submit-job
  └─ Input: {job_id, user_id, model, script, duration_seconds}
  └─ Output: {job_id, status, estimated_cost_usd, budget_status}
  └─ Error 402: {error, budget_status} if over budget

================================================================================
🎓 UNDERSTANDING THE INTEGRATION
================================================================================

Three Tiers of Usage:

  TIER 1 (Free - Browser CPU)
    Upload photo → Edit → Render locally
    Cost: $0
    API calls: 0

  TIER 2 (Free - API Calls)
    Parse script → Estimate cost → Check budget → Poll status
    Cost: $0 (no side effects)
    API calls: Yes, but no reservations

  TIER 3 (Paid - Higgsfield Generation)
    Submit job (budget atomically reserved) → Poll → Download video
    Cost: $0.05-$0.10 per second
    API calls: Yes, with side effects

Budget Flow:
  1. User clicks "Generate"
  2. Frontend shows cost preview (free, no reserve)
  3. User approves
  4. Backend atomically reserves budget from daily/monthly allowance
  5. Job submitted to Higgsfield API
  6. User polls status (free)
  7. Video ready → Download MP4
  8. Actual cost charged (pending → charged)

📞 SUPPORT & TROUBLESHOOTING
================================================================================

Common Issues:

  "ModuleNotFoundError"
  └─ Fix: pip install -r requirements.txt

  "Port 5050 already in use"
  └─ Fix: lsof -ti:5050 | xargs kill -9 (Mac/Linux)
  └─ Fix: Get-Process | Where {$_.Port -eq 5050} | Stop-Process (Windows)

  "Tests fail"
  └─ Fix: python -m pytest test_higgsfield.py -vv -s (verbose output)

  "Database locked"
  └─ Fix: rm data/generation-worker.lock && npm run start

  "TypeError: higgsfield_client is None"
  └─ Expected: Mock tests work around missing SDK
